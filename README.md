# Circus Bridge Ops

Private working repo for **Circus Bridge**, the Addis Ababa talent agency that books Ethiopian circus artists internationally.

Start with [`CLAUDE.md`](CLAUDE.md). It holds the full project context, rules and decisions.

| Folder | What's in it |
|---|---|
| `research/` | Market research and strategy |
| `plan/` | 60-day plan, weekly messages and checklists |
| `sales-kit/` | Act sheets, agency one-pager, rate card, contract templates |
| `prospects/` | Agency/buyer lists (CSV). Mark each as verified or unverified |
| `artists/` | Roster info (no passport numbers or IDs, ever) |
| `content/` | Social posts: image prompts + IG/FB/LinkedIn captions |
| `automations/n8n/` | n8n workflow JSON exports |
| `assets/` | Logos and small images only (videos live in Google Drive) |

**Never commit:** passwords, API keys, `.env` files, passport scans or personal ID documents.
